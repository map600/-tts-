# XTTS 语音合成 GUI 应用程序

这是一个基于XTTS模型的图形用户界面应用程序，允许您通过简单的点击操作来合成语音。

## 功能特点

1. **文本合成**: 单条文本语音合成
2. **批量合成**: 批量文本语音合成
3. **参数调节**: 可调节温度、Top-K、Top-P等合成参数
4. **多语言支持**: 支持多种语言的语音合成

## 使用方法

### 运行应用程序

```bash
conda run -n myenv python "E:/大三下机器学习/pythonProject1/xtts_gui.py"
```

### 界面说明

#### 1. 文本合成选项卡
- **合成文本**: 输入您要合成的文本内容
- **参考音频**: 选择用于克隆声音的参考音频文件
- **语言**: 选择文本的语言
- **合成参数**: 调节温度、Top-K、Top-P等参数
- **输出文件**: 设置合成音频的保存路径

#### 2. 批量合成选项卡
- **文本文件**: 选择包含多个句子的文本文件（每行一个句子）
- **参考音频**: 选择用于克隆声音的参考音频文件
- **输出目录**: 设置合成音频文件的保存目录
- **语言**: 选择文本的语言

#### 3. 设置选项卡
- **模型信息**: 显示当前加载的模型信息
- **高级参数**: 调节长度惩罚、重复惩罚等高级参数

## 使用步骤

1. **启动应用**: 运行脚本后，应用程序会自动加载XTTS模型
2. **等待加载**: 模型加载完成后会弹出提示框
3. **选择功能**: 在选项卡中选择"文本合成"或"批量合成"
4. **设置参数**: 根据需要设置相应的参数
5. **开始合成**: 点击"开始合成"或"开始批量合成"按钮
6. **查看结果**: 合成完成后会在指定位置生成.wav音频文件

## 注意事项

1. 首次运行时需要等待模型加载完成（可能需要几分钟时间）
2. 建议使用GPU环境以获得更好的合成速度
3. 参考音频建议使用清晰、无噪音的语音文件
4. 批量合成时，文本文件应为UTF-8编码，每行一个句子
