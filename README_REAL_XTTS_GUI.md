# 真实 XTTS 语音合成 GUI 应用程序

这是一个真实的XTTS语音合成图形用户界面应用程序，能够真正调用XTTS模型进行语音合成。

## 功能特点

1. **真实的语音合成**: 调用训练好的XTTS模型进行实际语音合成
2. **直观的用户界面**: 简洁明了的操作界面
3. **文本输入**: 支持多行文本输入
4. **参考音频选择**: 可选择用于声音克隆的参考音频
5. **输出文件设置**: 可自定义输出文件路径
6. **多语言支持**: 支持多种语言选择（特别优化了中文支持）
7. **状态提示**: 实时显示操作状态
8. **后台模型加载**: 模型在后台自动加载，不影响界面响应

## 使用方法

### 运行应用程序

```bash
conda run -n myenv python "E:/大三下机器学习/pythonProject1/real_xtts_gui.py"
```

### 界面操作说明

1. **输入文本**: 
   - 在文本框中输入您要合成的文本内容
   - 支持中文和英文文本
   - 示例中文文本："你好，欢迎使用XTTS真实语音合成工具！"

2. **选择参考音频**: 
   - 点击"浏览"按钮选择参考音频文件
   - 支持 WAV 和 MP3 格式的音频文件
   - 参考音频将决定合成语音的音色和语调

3. **设置输出文件**: 
   - 在输出文件框中显示默认保存路径
   - 可点击"浏览"按钮选择其他保存位置
   - 输出文件格式为 WAV

4. **选择语言**: 
   - 从下拉菜单中选择文本对应的语言
   - 支持英语(en)、中文(zh)、西班牙语(es)、法语(fr)、德语(de)
   - 对于中文文本请选择"zh"

5. **开始合成**: 
   - 点击"开始合成"按钮启动语音合成过程
   - 首次运行时模型加载可能需要几分钟时间

### 中文语音合成特别说明

1. **语言设置**: 确保在语言下拉菜单中选择"zh"
2. **参考音频**: 建议使用中文语音作为参考音频以获得最佳效果
3. **文本格式**: 输入规范的中文文本，避免使用特殊符号

### 注意事项

1. **首次运行**: 
   - 首次运行时需要加载模型，可能需要3-5分钟
   - 请耐心等待状态提示变为"模型加载完成，可以开始合成"

2. **模型文件**: 
   - 确保 `E:/大三下机器学习/pythonProject1/final_model/` 目录下包含完整的模型文件
   - 必须包含: model.pth, config.json, vocab.json

3. **参考音频**: 
   - 建议使用清晰、无噪音的语音文件作为参考音频
   - 推荐使用训练数据集中的音频文件

4. **系统资源**: 
   - 语音合成过程会占用一定的CPU和内存资源
   - 建议在有足够内存的计算机上运行

## 故障排除

### 常见问题

1. **程序无法启动**:
   - 检查是否安装了Python和必要的依赖包
   - 确认模型文件路径是否正确

2. **模型加载失败**:
   - 检查模型文件是否完整且未损坏
   - 确认final_model目录下包含model.pth, config.json, vocab.json文件

3. **合成过程缓慢**:
   - 首次运行需要加载模型，属于正常现象
   - 建议在有GPU的环境下运行以提高速度

4. **输出音频质量不佳**:
   - 尝试更换更高质量的参考音频
   - 确保选择了正确的语言选项

### 技术支持

如遇到其他问题，请检查:
- Python环境是否正确配置
- 所有依赖包是否已安装
- 模型文件是否完整且未损坏
