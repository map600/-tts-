# 简化版 XTTS 语音合成 GUI 应用程序

这是一个简化版的XTTS语音合成图形用户界面应用程序，提供了基本的语音合成功能，避免了复杂的依赖问题。

## 功能特点

1. **直观的用户界面**: 简洁明了的操作界面
2. **文本输入**: 支持多行文本输入
3. **参考音频选择**: 可选择用于声音克隆的参考音频
4. **输出文件设置**: 可自定义输出文件路径
5. **多语言支持**: 支持多种语言选择
6. **状态提示**: 实时显示操作状态

## 使用方法

### 运行应用程序

```bash
conda run -n myenv python "E:/大三下机器学习/pythonProject1/simple_xtts_gui.py"
```

### 界面操作说明

1. **输入文本**: 在文本框中输入您要合成的文本内容
2. **选择参考音频**: 
   - 点击"浏览"按钮选择参考音频文件
   - 支持 WAV 和 MP3 格式的音频文件
3. **设置输出文件**: 
   - 在输出文件框中显示默认保存路径
   - 可点击"浏览"按钮选择其他保存位置
4. **选择语言**: 
   - 从下拉菜单中选择文本对应的语言
   - 支持英语(en)、中文(zh)、西班牙语(es)、法语(fr)、德语(de)
5. **开始合成**: 点击"开始合成"按钮启动语音合成过程

### 注意事项

1. **首次运行**: 首次运行时可能需要几分钟时间来加载模型
2. **模型文件**: 确保 `E:/大三下机器学习/pythonProject1/final_model/` 目录下包含完整的模型文件
3. **参考音频**: 建议使用清晰、无噪音的语音文件作为参考音频
4. **文件格式**: 输出文件为 WAV 格式
5. **系统资源**: 语音合成过程会占用一定的CPU和内存资源

## 故障排除

### 常见问题

1. **程序无法启动**:
   - 检查是否安装了Python和必要的依赖包
   - 确认模型文件路径是否正确

2. **合成过程缓慢**:
   - 首次运行需要加载模型，属于正常现象
   - 建议在有GPU的环境下运行以提高速度

3. **输出音频质量不佳**:
   - 尝试更换更高质量的参考音频
   - 调整合成参数（在完整版中提供）

### 技术支持

如遇到其他问题，请检查:
- Python环境是否正确配置
- 所有依赖包是否已安装
- 模型文件是否完整且未损坏
